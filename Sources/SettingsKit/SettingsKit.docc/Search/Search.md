# Search

Make controls discoverable and render search results with their live bindings.

@Options {
    @TopicsVisualStyle(detailedGrid)
}

## Overview

Individual controls opt into search with an `indexed` modifier. The index contains metadata; each host resolves results to live views. Excluded subtrees remain available through normal navigation.
